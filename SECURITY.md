# Política de segurança

## Versões com suporte

Só a versão mais recente (a última [Release](https://github.com/Ejurevics/API-Controle_Canhotos/releases/latest)) recebe correções de segurança.

## Como reportar uma vulnerabilidade

Não abra uma issue pública. Use o reporte privado do GitHub: aba **Security** do repositório → **Report a vulnerability**.

Inclua, se possível:

- a versão ou o commit afetado;
- a rota ou o componente envolvido;
- os passos para reproduzir e o impacto esperado.

Este é um projeto pessoal, mantido sem prazo garantido de resposta. O reporte é confirmado assim que for lido, e a correção sai numa nova versão, com crédito a quem reportou, se desejar.
